StatNusa is a static national statistics site for Indonesia: population, economy, labour and prices, with a searchable data table and CSV download. It runs from the app/ folder with no build step and loads nothing over the network.

Open app/index.html through `node serve.ts`, or run `node main.ts` to hand the site in.
